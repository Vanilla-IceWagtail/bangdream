# assets/fruits —— 放水果原图的目录（可选）

如果你想直接把图片交给我，可以按下面的名字把 11 张图放进这个目录，
我会把它们压缩、内嵌进 `js/assets-builtin.js` 并锁定（之后游戏里不可再改）。

```
01-cherry.png       樱桃    建议 ≥ 80×80
02-strawberry.png   草莓    建议 ≥ 96×96
03-grape.png        葡萄    建议 ≥ 116×116
04-orange.png       橘子    建议 ≥ 140×140
05-kiwi.png         猕猴桃  建议 ≥ 168×168
06-tomato.png       番茄    建议 ≥ 200×200
07-peach.png        桃子    建议 ≥ 240×240
08-pineapple.png    菠萝    建议 ≥ 288×288
09-coconut.png      椰子    建议 ≥ 348×348
10-melon.png        哈密瓜  建议 ≥ 416×416
11-watermelon.png   西瓜    建议 ≥ 500×500
```

- 格式：PNG / WebP（要透明背景就用这两种）。
- 命名不严格要求英文：`樱桃.png`、`01.png`、`1-西瓜.png` 也认。
- 如果图片尺寸不够，「合成大西瓜」的思路是——放大后水果会有点糊；宁可大一点，导入时会自动缩到最长边 384px。

更省事的方式是**在游戏里用「贴图工坊」导入，然后导出贴图包（.json）发给我**，那样连命名都不用管。
