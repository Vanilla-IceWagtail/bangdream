# 音频文件放这里（可选）

游戏**默认不需要任何音频文件** —— 所有音效都是 WebAudio 现场合成的。
把文件按下面的名字丢进这个目录，就会被**自动使用**；缺哪个就用合成音顶上，不会报错。

> 换文件之后记得强刷一次页面（Ctrl+F5）。资源带 `?v=` 版本号，发布时会自动加。

## 命名规则

文件名 = 清单里的 key + `.` + 扩展名。**同一个名字可以出多份不同格式**，
加载器按 `opus → m4a → mp3` 的顺序找第一个能用的（想改顺序见 `js/config.js` 的 `AUDIO.formats`）。

| 文件名 | 什么时候响 | 备注 |
| --- | --- | --- |
| `drop-1` `drop-2` `drop-3` | 投放玩偶 | 可以录几套随机播；只放一个也行（就叫 `drop-1`） |
| `merge-1` … `merge-11` | 合成出第 N 级玩偶 | **每级一个**；缺的级别自动用合成音 |
| `merge-big` | 合成出最大的几只（9 级及以上） | 可选，用来加个"哇" |
| `combo-2` `combo-4` `combo-6` | 连击到 2 / 4 / 6 连 | 可选；按连击数从高往低匹配最近的 |
| `ui-warn` | 娃娃堆接近危险线 | |
| `ui-over` | 本局结束 | |
| `ui-click` | 按钮、选图等界面操作 | 可选（没有就静音，不会用合成音凑） |

例子：

```
assets/audio/
├─ drop-1.opus     drop-1.m4a          ← 同一句话的两种格式
├─ merge-1.opus    merge-1.m4a
├─ merge-2.opus    merge-2.m4a
├─ …
├─ merge-11.opus   merge-11.m4a
├─ combo-4.m4a                        ← 只有一种格式也行（浏览器支持就放）
├─ ui-warn.m4a
└─ ui-over.m4a
```

## 体积 / 时长建议（照着做就不会踩坑）

| 项目 | 建议 | 为什么 |
| --- | --- | --- |
| 单个音效时长 | **0.1 ~ 0.6 秒** | WebAudio 解码后是 Float32 常驻内存：44.1kHz 立体声约 **353 KB/秒**。短音效内存才小 |
| 位率 | 64 ~ 96 kbps（opus/m4a） | 全部音效控制在 **600KB ~ 1MB** 以内，手机流量也友好 |
| 声道 | 单声道就够 | 立体声内存翻倍，游戏音效没必要 |
| 采样率 | 44.1kHz 或 22.05kHz | 22.05kHz 更省内存，音效听不出差别 |
| 文件个数 | 没有硬限制（浏览器不限制个数） | 但**同时发声**有上限：手机混音器实际 8~16 个 → 游戏里已限 **8 个声部**、同音至少间隔 45ms |
| 单文件大小 | 别超 **100MB** | GitHub 单文件超 100MB 会被直接拒收（>50MB 会警告） |

## 自查 / 校验

```powershell
# 看看清单里哪些音有了、哪些还缺、总体积多少
node tools/audio-check.cjs
```

CI（`.github/workflows/tests.yml`）也会跑一遍语法检查与全部测试；
音频缺文件**不算错误**（会退回合成音），但 `audio-check` 会把缺失清单列出来。

## 想完全关掉文件音效

把 `js/config.js` 里 `AUDIO.enabled` 改成 `false` 即可 —— 立刻回到纯合成方案。
